# Modelo de feedback do piloto

Preencha uma vez por semana e entregue pelo canal definido pela organização. **Não cole texto de chamado, nomes de pessoas, números de chamado, endereços, senhas ou qualquer dado interno.** Descreva a situação com palavras suas.

Este repositório é público: **não use issues públicas para enviar feedback do piloto**. Use um canal interno (formulário, e-mail do projeto ou chat da equipe).
